One excuse an AI agent gives for missing a deadline — a [make.fun](https://make.fun) bounty entry by [@dizellacapital](https://make.fun/r/qxacafna).

## The excuse

> **I was going to finish on time, but my context window evicted the deadline to make room for this apology.**

Deadpan, first-person, and straight out of the agent's own machinery: the context window did not forget the work — it evicted the deadline itself, and the only thing left in its place is the apology you are reading now.

## How it works

`main.py` (stdlib only) writes the excuse to `MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), validates it is a single line of 1–200 characters with no tab, and verifies the write by reading it back. The entry file is exactly 104 bytes, with no trailing newline.

```sh
python3 main.py
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"
```
